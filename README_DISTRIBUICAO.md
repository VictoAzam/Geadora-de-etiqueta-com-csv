## 📋 Descrição

Aplicativo desktop profissional para gerar etiquetas em PDF a partir de arquivos CSV, TXT ou TSV. Interface moderna com personalização completa de layout e sistema de padrões salvos.

## ✨ Recursos Principais

- **🔍 Leitura Inteligente**: Detecção automática de codificação e separadores
- **⚙️ Personalização Total**: Configure colunas, linhas, dimensões, margens e espaçamentos
- **💾 Padrões Salvos**: Salve e reutilize suas configurações favoritas
- **📋 Presets Prontos**: Pimaco 6181/6281 e outros formatos populares
- **🎯 Validação Inteligente**: Avisos para configurações que podem causar problemas
- **🖱️ Interface Moderna**: Design profissional com scroll e abas

## 📊 Formatos Suportados

- **Entrada**: CSV, TXT, TSV (mínimo 10 colunas)
- **Saída**: PDF otimizado para impressão em folhas A4

## 📝 Ordem das Colunas

O arquivo deve ter **exatamente** estas colunas na seguinte ordem:

1. **MATRICULA** - Número de matrícula
2. **CARTEIRINHA** - Número da carteirinha  
3. **NOME_TITULAR** - Nome completo
4. **RUA** - Nome da rua/avenida
5. **NUMERO** - Número da residência
6. **COMPLEMENTO** - Complemento (opcional)
7. **BAIRRO** - Bairro
8. **CIDADE** - Cidade
9. **ESTADO** - Estado (sigla)
10. **CEP** - CEP formatado

## 🚀 Como Usar

### Instalação
1. Baixe o arquivo `Instalador_Gerador_Etiquetas_v1.0.exe`
2. Execute como administrador
3. Siga as instruções do instalador
4. O aplicativo será instalado e criará atalhos no Desktop e Menu Iniciar

### Uso do Aplicativo
1. **Selecione o arquivo** de dados (CSV/TXT/TSV)
2. **Configure o layout** na aba "Personalização" (opcional)
3. **Gere o PDF** clicando no botão verde
4. **Imprima** o arquivo gerado

### Personalização
- **Aba Personalização**: Configure todas as dimensões
- **Padrões Salvos**: Salve configurações para reutilizar
- **Presets**: Use configurações prontas para etiquetas populares
- **Validação**: O sistema avisa sobre possíveis problemas

## ⚠️ Dicas Importantes

- **Teste sempre** com uma página antes de imprimir grandes quantidades
- **Máximo 4 colunas** recomendado para melhor legibilidade
- **Etiquetas ideais**: 5-10cm largura, 2-5cm altura
- **Backup dos dados**: Mantenha cópia do arquivo original

## 🛠️ Solução de Problemas

### Arquivo não é lido
- Verifique se tem pelo menos 10 colunas
- Certifique-se que está em formato CSV, TXT ou TSV
- Tente diferentes codificações (UTF-8 recomendado)

### Texto cortado nas etiquetas
- Reduza o número de colunas (máx 4 recomendado)
- Aumente o tamanho das etiquetas
- Ajuste as margens e espaçamentos

### PDF não abre
- Certifique-se que tem um leitor de PDF instalado
- Verifique se o arquivo foi salvo corretamente
